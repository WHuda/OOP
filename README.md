### ПЗ 1. Ответы на вопросы.
- Упражнение 1: Почему scaled возвращает новый объект, а не меняет self? Что изменилось бы для второго теста, если бы метод менял self? 
- Ответ: Метод возвращает новый объект, чтобы не изменять исходный вектор. По условию задания (и по тестам) метод, должен возвращать именно новый вектор, а не измененный изначальный. Если бы метод scaled изменял self, то во втором тесте, изначальный метод бы изменил значения на (3, 6) и проверка бы не прошла.

- Упражнение 2: Где должен создаваться список значений и почему второй тест провалится, если создать его в теле класса?
- Ответ: Список значений в данном случае должен создаваться в конструкторе, т.е. отдельно для каждого объекта. Если создать в теле класса, то он станет общим атрибутом и будет использоваться всеми экземплярами, в таком случае второй тест на проверку независимости аккумуляторов не будет пройден.

- Упражнение 3: Напечатается "x", потому что атрибут lines создан в теле класса и является общим для всех объектов Log. Объекты a и b используют один и тот же список. Поэтому, когда объект a добавляет в него "x", объект b видит уже изменённый список.
